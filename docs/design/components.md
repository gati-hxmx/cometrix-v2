# 部品（コンポーネント）づくりの基本ルール

新しい部品や画面を作るときは、まずこのルールに合わせます。共通の配置は [基本ルール](layout.md)、色は [配色](colors.md)、絵は [アイコン](icons.md) にあります。

どの部品も「見てわかる」「打たずに選べる」「まちがえても戻せる」を目指します。

## 0. 2つの柱

- **見て操作する**：グラフ・図・カレンダーにして、見たまま操作できるようにする。
- **文字を打たせない**：文字の入力をできるだけなくし、マウスか指のタップだけで使えるようにする。

## 1. 見て操作する

- **1-1 データの形に合った図を使う**
  - 日付 → カレンダー
  - 時間 → 時間の帯
  - 金額・推移 → 棒グラフ
  - 過不足 → 薄い色の濃さ（足りない所だけ薄い赤）
- **1-2 図そのものを押して操作する**：図は見るだけにせず、マスや帯を押す・つかむと、そこから追加・変更できるようにする。図の外に同じ働きのボタンを並べない。
- **1-3 状態は記号＋色＋形で**：○ 緑・△ 黄・× 赤、未入力は点線、下書きは薄く、⚠ は要確認。色だけに頼らない（[基本 8](layout.md#8-押しやすさ読みやすさお知らせ)）。同じ意味はどの画面でも同じ見た目にする。
- **1-4 ひと目で全体、押すと詳しく**：図には数字1つと記号だけを出し、細かい内容はマウスを乗せる・押すと出す。

## 2. 文字を打たせない

- **2-1 入力は「選ぶ」に置きかえる**
  - 時刻 → 一覧から選ぶ（予定は30分ごと、実際にあったことの記録は15分ごと）
  - 日付 → カレンダーから押す
  - 人 → 名前の丸を押す
  - 少ない数 → − / ＋ のボタン
  - よく使う値 → ボタン（例：「3日前・5日前・7日前」）
- **2-2 最初から答えを入れておく**：前回・前の1件・決まりの値を入れておき、直すだけにする。
- **2-3 押した場所で中身を決める**：押したマスの「だれ・いつ・どこ」はもう決まっているので、パネルで選び直させない（[基本 6-2](layout.md#6-2-パネルの決まり)）。
- **2-4 まとめて入れる・写す**：同じ内容を何度も入れさせない。「まとめて入れる」「次の日にコピー」「前の週をコピー」を用意する。
- **2-5 文字は写真や定型文で代わりに**：紙は写真、送る文はできあがった文面をコピー。
- **2-6 どうしても文字が要るもの（名前・メモ）は**：畳んでおき、必要な人だけ開く。書いたそばから自動で保存する。
- **2-7 ブラウザ標準の部品をそのまま見せない**：確認ダイアログ（`confirm`）・ファイル選択（「Choose Files」と英語で出る）・プルダウン・文字の検索欄は、言語や見た目がそろわず、初心者が迷うので使いません。確認は 4-2 の表、写真は大きな［写真を撮る・選ぶ］のボタン、人は名前の丸、選ぶものはチップ（選択ボタンの並び）にします。
  - **人・種類・対象・金額**：1つ選ぶものはチップの並び、人は名前の丸（色は [配色](colors.md) の識別色）を付けたチップ。金額はよく使う額のチップと「ほかの額 ▾」。半端な額のときだけ数字の欄を出し、スマホは数字のキーボードにします。
  - **例外：時刻と日付は、スマホ・PC の標準の部品を使います**。見た目は大きなボタン「20:00 ▾」「11/6 (金) ▾」で、押すと端末の標準の選び方（iPhone は回す列・カレンダー）が開きます。終わりが始まりより前なら自動で翌日にし、組には長さ（「7時間」）を出します。日付のボタンには「今日・昨日・明日」の小さな札。
  - 20件ほどまでの一覧は検索欄を置かず、札で絞ります（[基本 11](layout.md#11-メニューと一覧)）。

経緯：2026-11-07（[経緯](history.md#部品-2-7-時刻日付は標準の部品例外)）。

## 3. 文字の表示はアイコン中心にして場所を取らない

- **3-1 ボタンと札はアイコンだけを基本にする**：名前はマウスを乗せたとき（PC）に小さく出し、読み上げ用の名前は必ず付ける。状態も言葉より記号で伝える（休みは ✕ だけで「休み」と書かない）。切り替えの札は、選んでいるものだけ名前を出す（[基本 4](layout.md#4-切り替えボタンの位置)）。スマホの長押しは小さなメニュー（4-9）に使うので、名前を出すのには使わない。
- **3-2 アイコンは全画面で1つの意味に決め、同じ形式でそろえる**：同じアイコンを別の意味に使わない。使うアイコンと意味は [アイコン](icons.md) で管理し、新しい意味はそこに足してから使う。絵はすべて**線のアイコン**で、**絵文字は使わない**。
- **3-3 言葉を残すもの**：取り返しにくい操作とお金に関わる操作（公開する・確定する・削除する・支払いを記録）、画面の主な1つのボタン、注意とエラーの文、金額とその名前は言葉で出す。パネルの「✕ 閉じる」も文字を残す（[基本 6-2](layout.md#6-2-パネルの決まり)）。
- **3-4 説明の文は1か所**：使い方の説明は画面の中に並べず、「使い方」のパネルにまとめる。
- **3-5 アイコンはどの言語でも通じるものを選ぶ**：特定の言語の文字や、一部の文化でしか通じない絵は使わない。
- **3-6 短い名前を最初から用意する**：対応する言語のうち長くなる言語を前提に、切り替えの札・タブ・ボタン・曜日など幅の決まった所には、作るときに短い名前も用意する。読み上げ用には元の長い名前を残す。375px で1行に入らないときは、文字を小さくせずに短い名前に替える。

経緯：2026-11-01・11-06（[経緯](history.md#部品-3-アイコン)）。

## 4. 操作のしかた

- **4-1 マウスと指の両方で同じことができる**：PC のドラッグ・右クリック・キーの近道は「近道」とし、同じことが必ず「押す → パネル」でもできるようにする（右クリック＝長押し）。
- **4-2 確認より「元に戻す」**：取り返せる操作はすぐ保存して「元に戻す」を出す。確かめる画面は取り返しにくいときだけ。どれにするかは次の表で決め、新しい操作もこの表に足してから作ります。

  | 分け方 | 例 | 形 |
  | --- | --- | --- |
  | すぐ保存＋元に戻す | ふつうの追加・変更・削除、設定の選択ボタン | 右上のお知らせに［元に戻す］（[基本 8-1](layout.md#8-1-右上のお知らせすぐ消えるお知らせ)） |
  | パネルの中で1回だけ聞く | 公開済みのものの削除、確定と解除、データのリセット | 「n件を確定しますか？［戻る］［確定する］」を押したボタンの所に。ブラウザの確認ダイアログは使わない（2-7） |
  | 言葉のボタンで、その画面で行う | 公開、外への送信 | やることの札から画面へ移り、言葉のボタン（3-3）で行う（[基本 8-2](layout.md#8-2-やることホーム)） |

  「すぐ保存＋元に戻す」は、消したものをふだんの保存の処理で作り直す形にし、権限やロックの確かめを飛ばさないようにします。

- **4-3 選んだ結果をその場で1行で見せる**：「10/19(月)〜10/25(日) · 7日間 · 締切 10/13(火) 23:59」のように確かめられるようにする。
- **4-4 選べないものは最初から選べなくする**：期間の外の日、選べない人は薄くして押せなくする。エラーで止めるより先に防ぐ。
- **4-5 選ぶ数を減らす**：候補が多いときは、合うものだけを前に出し、ほかは畳む。
- **4-6 空のときは次の一歩を示す**：何もないときは空白にせず、「まだ〇〇がありません」と次にすることを1行で出す。
- **4-7 キーボードでも最低限使える**：Tab・Enter・Esc で選ぶ・閉じるができること。
- **4-8 見えない操作は知らせる**：ドラッグやキーの近道は、初めてのときだけ短い札で知らせ、「使い方」にまとめる。

### 操作の工夫

どれも 4-1 のとおり、押す → パネルでも同じことができるときだけ作ります。指の操作を先に考えます。

- **4-9 押す・長押し**：押すとその場のパネル、長押し（PC は右クリック）で小さなメニュー。
- **4-10 つかんで動かす・伸び縮み**：帯や札をつかんで別の時間・日へ動かし、端を引いて長さを変える。Ctrl（Mac は ⌘）を押しながら離すとコピー。
- **4-11 なぞって範囲を選ぶ**：空いた所をなぞると、その範囲を選ぶ。
- **4-12 吸い付く**：動かす・伸ばす・なぞるとき、目盛り（30分など）に吸い付く。
- **4-13 置く前に結果を見せる**：動かしている間は置いたあとの形を薄く出し、置けない所は赤くして、離しても置かない。
- **4-14 元に戻す**：動かした・消したあとは、右上のお知らせの［元に戻す］で戻せる（4-2）。
- 候補（作るときに上へ移し、確かめ方を [基本 10](layout.md#10-確認のしかた) に足す）：左右にスワイプで前後へ、2本指で広げる・縮める、記号を選んでからなぞって塗る、PC の近道（オートフィル・Shift／Ctrl＋クリック・キーの近道）。

経緯：2026-10-31・11-01（[経緯](history.md#部品-4-操作のしかた)）。

## 5. 共通部品を使い回す

新しい画面は、次の部品の組み合わせで作ります。同じ働きの部品を画面ごとに作り直しません。部品は共通部品のフォルダ（stack-select で決める。Next.js なら `src/components/ui/`）に1つずつ置き、色や寸法は [配色](colors.md) の変数だけを使います。

- カレンダー（5-2）
- 時間の帯の表
- ○△× のボタン
- 時刻の選択（2-7 の例外）
- − / ＋ の数の選択
- 選択ボタンの並び（チップ）と名前の丸
- パネル（PC は右、スマホは下）と中央の白い枠（[基本 6](layout.md#6-変更はページを移らずにパネルで)）
- 1件1行の一覧（畳むつき）
- 大きな数字のカード
- 右上のお知らせ（[基本 8-1](layout.md#8-1-右上のお知らせすぐ消えるお知らせ)）
- アイコンボタン（名前つき、3）
- 設定の一覧（5-1）
- 工程バー（5-3）
- 対象の札と「名前 ▾」（5-4）
- 「いま」の札（5-5）
- 1行の印と 🔒（5-6）
- 数字の図と月の札（5-7）
- 一覧の表（5-8）
- 小さなメニュー（5-9）

部品は見本帳（Storybook か、アプリと同じ CSS を読む見本のページ）に置き、そこで見た目を確かめます。新しい部品は、ここに1行足してから作ります。

### 5-1 設定の一覧（アイコン・名前・右に今の値）

「今の値を見て、押して変える」ものは、どの画面でもこの形で並べます（[基本 5](layout.md#5-同じ情報は1か所にまとめる)）。

- **1行の形**：左にアイコン（44px の角丸の四角、[アイコン](icons.md) の置き方）、まん中に名前（太字）とその下に小さな説明1行、右に**今の値を太字**で（「末日」「10%」「17人」）、いちばん右に「›」。
- **行全体を押す**：行のどこを押しても開きます。同じ働きの「変更」「開く」ボタンを重ねて置きません。パネルを開く行の右端は「›」、別の画面へ移る行は「→」にします。
- **今の値は短く**：数字や1語にします。長い説明は名前の下の小さな文字に回します。値がないときは「⚠」を出します。ふつうの状態（「使用中」など）には値を書かず、例外（「使用しない」「未連携」）だけ書きます。
- **まとまりは枠で**：見出しつきの白い枠に、関係する行をまとめます。PC（1100px 以上）は枠を2列に、スマホは1列です。
- **追加の行**：一覧に足すものは、同じ枠の最後に「＋ 〜を追加」の行を置きます（点線の枠のアイコン、値なし）。
- **対応が要るときは行に印**：直さないと困ることがあるときは、その行の値を「⚠」にし、ホームのやることに出します。枠の上に黄色い注意は出しません。
- **パネルの中の項目へ**：パネルの行から、その項目の中身に替わるときは、上に「‹ 元の名前」のように戻るリンクを置きます（パネルを重ねない）。
- **パネルの中でも同じ形**で並べます（枠は1列）。

経緯：2026-10-27（[経緯](history.md#部品-5-1-設定の一覧)）。

### 5-2 カレンダー（月・期間）

日付が主役の情報は、この形のカレンダーで出します（1-1）。

- **土台**：大きな角丸の四角に大きな日付の数字、曜日は丸い札。休みは薄い赤（`--danger-weak`）の角丸と赤い枠（`--danger-line`）に小さな ✕。
- **形**：月曜はじまりの7列。上に曜日の見出しを1行。1日を角丸のマス1つにし、白い枠の中に隙間を空けて並べます。線でつないだ表にはしません。どの幅でも7列を横にスクロールさせずに入れます。
- **出す範囲**：見せる期間の週だけ。期間の外の日は日付だけ薄く出し、中身は出さず、押せません（4-4）。
- **曜日**：土は青（`--sat`）、日・祝は赤（`--danger`）。スマホは短い名前にし、2行に折ったり「…」で切ったりしません。
- **日付**：マスの左上に太字で。各月の1日と最初のマスだけ「11/1」、ほかは「2」。祝日の名前は PC だけ日付の下に小さく。
- **今日**：枠を 2px の `--accent` にし、日付の横に「今日」の札（`--accent` の地に白字）。スマホは札を出さず枠だけ。
- **選んだ日**：内側に 3px の `--accent` の枠。色を塗るだけで選択を伝えません。
- **過ぎた日**：これからを決めるカレンダーでは、過ぎた日のマスを `--surface-2`、日付を `--muted` にします。
- **マスの中身**：記号と数字1つまでの小さな札を重ねます（1-3・1-4）。中身が1つだけのカレンダーは、マス全体をその色にしてかまいません。
- **札の見た目**：確定は `--accent` の塗りに白字、下書きは白地に点線、要確認は先頭に ⚠、済みは ✓（`--ok-weak`）、押して入れる空きは点線と ＋、入力もれはマス全体を黄の点線と ⚠、なしは灰色の「—」、休みは ✕ だけ。
- **時刻の書き方**：マスの中は短く「19〜3」「19:30〜23:30」（分は0分以外のときだけ）。スマホは始まりだけ「19〜」。くわしい時刻はマウスを乗せたときと押したパネルで出します。
- **押したとき**：マス全体が押せます。中身が1つならその変更、空いた日はその日の追加（2-3）、2つ以上ならマスの中の札ごとに押せます。押すとその場のパネル。
- **前後へ**：見出しの右に「‹ 10/26〜11/08 ›」（丸い 44px のボタン）。今日を含まない期間を見ているときだけ「今週に戻る」「今月に戻る」。
- **凡例**：カレンダーのすぐ下に、記号の見方を小さな字で1行。
- **読み上げ**：マスごとに日付と中身を読み上げます。

| 部分 | 寸法と色 |
| --- | --- |
| 枠 | `--surface`、1px の `--line`、角丸 `--radius`（10px）、内側 6px |
| マスの並び | 隙間 4px |
| マス | 角丸 8px、1px の `--line`。高さ PC 84px・スマホ 64px・パネルの中 52px |
| 曜日の見出し | .78rem・太さ600・`--muted` |
| 札 | 角丸 5〜6px、薄い地と細い線。色は [配色](colors.md) の変数だけ |
| 凡例 | .8rem・`--muted` |

経緯：2026-10-30・11-06（[経緯](history.md#部品-5-2-カレンダー)）。

### 5-3 工程バー

仕事の順番（例：「① 受付 → ② 下書き → ③ 調整 → ④ 公開」）を1本で見せる部品です。

- 各工程は番号と名前、その下に1行の状態（「⚠ 未入力 n件」「n / m人」）。数は [基本 12](layout.md#12-数え方どの画面でも同じ数にする) のとおり。
- そろった工程は ✓、要確認は ⚠、まだ始められない工程は点線。最初のそろっていない工程を今の工程として濃くします。
- 押すと、その工程の作業の場所が直接開きます。状況を見せるだけの中継のパネルは置きません。
- スマホは1行で、今の工程だけ名前を出し、ほかは丸（✓ か番号）だけ。
- ほかの入口（タブ・ボタン）と重なる工程はバーにせず、代わりの入口がない工程だけをボタンで残します。

### 5-4 対象の札と「名前 ▾」

対象（店・チームなど）がいくつになっても上の枠の高さが変わらないようにする部品です（[基本 4](layout.md#4-切り替えボタンの位置)）。

- **対象の札**（全部まとめて見る画面で、一覧を絞るだけ）：「全部｜A ⚠ 4｜B」の丸い札を1行で横にスクロール。数字はいつも全部のまま。
- **「名前 ▾」**（対象ごとに作業する画面）：上の枠の左端に札1つ。押すとすぐ下に対象の一覧の小さなメニュー（5-9）で、各対象の注意を1つ。ほかの対象に注意があるときは札にも小さな ⚠。対象が1つなら名前だけ。

### 5-5 「いま」の札

その人・その画面の「いま」を2〜4枚の札で見せる部品です。

- 1枚に名前・大きな数字か日付1つ・下に1行。対応が要るときだけ ⚠ と黄色の字（1-3）。
- 押すと、その作業の場所が開きます。
- スマホは2×2、900px 以上は横に並べます。

### 5-6 1行の印と 🔒

- **1行の印**：やることに出したことを、関係する場所で1行だけ知らせます（「⚠ 入力もれ：1件 ›」）。枠は付けず、押すとその作業へ。置くのは関係する箱・表・パネルの中か下で、上のメニューと本体のあいだには置きません（[基本 2-1](layout.md#2-1-上のメニューと本体のあいだには何も置かない)）。
- **🔒 状態**：確定済み・締切済みで変えられないことを、灰色の 🔒 と1文で。黄色にしません。

### 5-7 数字の図と月の札

- **横棒**（済み｜残り）・**内訳の帯**・**足し算の図**（レシートのように「… ＝ 合計 − 済み ＝ 残り」）を使います。棒や帯は飾りで、数字は必ず横に書きます。色は [配色](colors.md) の系列色だけです。
- **月の札 ▾**：「‹ 2026/10 ▾ ›」を押すと年と1〜12月のパネルで、月ごとに小さな印と、いちばん大事な1行（「⚠ n日」「✓ 済み」）。

経緯：2026-10-31（[経緯](history.md#部品-5-35-7-工程バー対象の札いまの札1行の印数字の図)）。

### 5-8 一覧の表（見出しの行で絞り込み・並び替え）

人や物を1件1行で並べる表の決まりです。

- **列**：1列に1つのこと。同じことを2つの列に重ねて出しません。いくつも入る列は、主なものを太字で先頭に、ほかをその後ろに続けます。
- **絞り込みと並び替えは見出しの行から**：各列の見出しを「種類 ▾」にし、押すとその列の下に小さな枠が開きます。枠の中は「絞り込み」と「並び替え」の2段で、どちらもチップ。押すとすぐ一覧が変わります。表の上に札やプルダウンの枠を別に置きません。
  - 絞り込みは「すべて」と、いる値だけ（数つき「正社員 · 1」。0件の値は出さない）。
  - 並び替えは列ごとに2つ（「高い順・低い順」など）。未設定はいつも最後にします。
  - 絞り込み中の列は見出しに今の値、並び替え中の列は ↓↑。
  - 開けるのは1つだけ。外を押すか Esc で閉じます。条件は URL に残し、詳細から「‹ 一覧」で同じ並びに戻れるようにします。
- **スマホ**：見出しの行は「種類 ▾」のボタンを横に並べた行になり（折り返してよい）、枠はその行の下いっぱいに出ます。行は「名前と大事な数字」の下に、残りの列を1行にまとめます。
- **合う行がないとき**も見出しの行は残し、「条件に当てはまるものはありません。」と［絞り込みを解除］を出します。

経緯：2026-11-03（[経緯](history.md#部品-5-8-一覧の表)）。

### 5-9 小さなメニュー

1つ選ぶだけのもの（[基本 6-1](layout.md#6-1-パネルにするかの判断) の 2）を、押したボタンのすぐ下に出す部品です。サイドパネルより目の動きが少なく、元の画面も隠しません。

- **出る場所**：押したボタンのすぐ下。PC はボタンの幅以上（17〜24rem）で、画面の右端に近いボタンは右にそろえます。スマホ（600px 未満）は横いっぱい（左右 16px）。画面を暗くしません。
- **行**：1行 48px 以上。今の値は薄い色の行に ✓、注意は行の右に、別の画面へ移る行は右に › か →。2行目の説明は小さな灰色の字で1行まで。
- **閉じ方**：選ぶとすぐ切り替わって閉じます。外を押す・Esc・もう一度ボタンでも閉じます。「✕ 閉じる」は置きません。開けるのは1つだけ。
- **数が増えたとき**：高さは画面の6割までで、それ以上は中でスクロールします。
- **中身**：リンクの一覧、つながった札、すぐ保存する選択、数行の説明（ⓘ）。入力欄が要るものや、選ぶものが12個を超えるものはパネルにします。
- **使わないもの**：ブラウザの `<select>`（⚠ や ✓ が出せず、iPhone では回転式になって見た目が離れるため）。
- 中身はリンクにし、JavaScript が動かなくても選べるようにします。

経緯：2026-11-04（[経緯](history.md#部品-5-9-小さなメニュー)）。

## 6. AI の読み取りの結果と外のサービス

写真や文書を AI などで読み取るとき、外のサービスにデータを送るときの決まりです。

- **6-1 読んだものをそのまま登録しない**：読み取りの結果は下書きとして出し、人が確かめてから登録します。自動で登録するのは、決めた条件（紙の合計と計算が一致するなど）が全部そろったときだけにし、「未確認」の印を付けて人があとで見る形にします。この自動登録は設定のスイッチで、初めはオフにします。
- **6-2 1行ずつ見くらべる**：元の行ごとに「写真の切り抜き → 読んだ内容 → ✓ / ⚠」と並べ、切り替えずに見くらべられるようにします。
- **6-3 ⚠ はその場の答えのボタンで直す**：選ぶだけで直せるようにします（2-1）。⚠ が残っているあいだ、主なボタンは「⚠ あと n か所を確かめる」（押すと次の ⚠ へ）にし、0 になったら［登録］にします。
- **6-4 合計で照らし合わせる**：元に合計が書いてあれば「書かれた合計 ＝ 計算 ✓」と出し、合わないときは差額を出します。
- **6-5 直した答えを覚える**：直した読み方を覚え、次から自動で当てます。
- **6-6 外に送るものを見せる**：写真や個人の名前を外のサービスに送るときは、送る前に何を送るかを1行で出します。鍵はアプリの設定（秘密の変数）にだけ置き、コード・Issue・ログに書きません（[AGENTS.md](../../AGENTS.md)）。
