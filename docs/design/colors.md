# 配色

どの画面もこの配色で作ります。Cometrix の色は、2026-11-12 のアプリの最初の見た目（#2）でオーナーが選んだ青の配色（青白い地・白い面・青）です（[経緯](history.md)）。テンプレートの標準（Hana のベージュ×青緑）から値だけを替えています。アプリの最初に design スキルで別の色を選んだときは、変数の値だけを替え、変数の名前と使い分けはそのままにします。

## 1. 画面の基本

| 用途 | 変数 | 標準の色 |
| --- | --- | --- |
| ページの地 | `--bg` | `#f6f8fb` 青白い地 |
| カード・表・パネル | `--surface` | `#ffffff` 白 |
| 補助の面・ホバー・過ぎた日 | `--surface-2` | `#eef2f7` |
| 区切り線 | `--line` | `#d5dde8` |
| 本文 | `--text` | `#1b2430` |
| 補足 | `--muted` | `#566373` |
| 主な操作・リンク・今日 | `--accent` | `#2c5a96` 青 |
| 強調の文字・主な操作のホバー | `--accent-dark` | `#1f4372` |
| 選択中・アイコンの地 | `--accent-weak` | `#e3ecf7` 薄い青 |
| 薄い青の枠 | `--accent-line` | `#9db7da`（`--accent` を少し薄めた色） |
| 土曜日の字 | `--sat` | `#1f5fa8` 青（日・祝は `--danger`） |
| 角丸 | `--radius` | `10px` |

- **基本は白い面と細い枠**です。大きな面を鮮やかな色で塗らず、色は線・印・アイコン・薄い地に使います。
- **赤は強すぎるので面には使いません**。薄い赤（`--danger-weak`）と赤い枠（`--danger-line`）にします。
- 目立たせるのは、足りない所・休みなど見てほしい所だけです。PC の札も白い地に少し薄めの色で並べます。
- 主な操作だけ `--accent` の塗りのボタンにします。
- 選んでいる状態は、地の色だけでなく、枠・下線・✓ でも伝えます。

## 2. 状態を伝える色

| 意味 | 文字・印 | 地 | 枠 |
| --- | --- | --- | --- |
| 注意・未入力 | `--warn` `#7a4d00` | `--warn-weak` `#fff3d6` | `--warn-line` |
| エラー・削除・不足 | `--danger` `#a3261b` | `--danger-weak` `#fdecea` | `--danger-line` |
| 完了・成功 | `--ok` `#1d6b40` | `--ok-weak` `#e3f4ea` | `--ok-line` |

- 枠の線は、地より少し濃い専用の変数（`--*-line`）を使います。下書きは `--draft-line` と `--draft-bg` の点線です。
- **黄色は「対応が要る印」だけ**に使います（⚠・点線・未入力の札）。やることの数は灰色の丸札で、赤は急ぐものだけです。画面の上の黄色い枠の注意は出しません（[基本 8](layout.md#8-押しやすさ読みやすさお知らせ)）。
- 変わらない説明（デモの注意書きなど）は、関係する要素の中や下の灰色の小さな字にします。確定済み・締切済みは灰色の 🔒 です。
- 緑は完了・成功の小さな印とお知らせを中心に使います。注意の色を飾りに使いません。
- 色だけで意味を伝えず、文字や記号を添えます。濃い文字と薄い地を組み合わせます。

## 3. グラフの系列色

| 変数 | 標準の色 |
| --- | --- |
| `--chart-1` | `#78a8e8` 青 |
| `--chart-2` | `#80c8b8` ミント |
| `--chart-3` | `#f2b88e` アプリコット |
| `--chart-4` | `#bcc7d3` 青みのグレー |
| `--chart-minus` | `#a3261b` 赤（引く値だけ） |

- 明るさと見分けやすさを両立した「さわやか」の組み合わせです。棒・凡例・内訳の印は同じ系列色にし、文字は本文の色にします。
- 系列色はデータを見分けるためだけに使い、ボタンや選んでいる状態には使いません。選んだ棒の地は `--accent-weak`、印は `--accent` です。
- 1番目の系列の薄い地が要るときは `--chart-1-weak`（`#dceafa`）、その上の字は `--chart-1-text`（`#2c5a96`）です。

## 4. 識別色（人・対象）

人や対象（店・チームなど）を色で見分けるときは `--id-0`〜`--id-7` を並び順に使い、9番目からは最初に戻ります。標準の色は `#6f9fd8` 青・`#e3a95f` 山吹・`#7fbf9c` 緑・`#b39ddb` 藤・`#e39a9a` 薄紅・`#a9b6c3` 灰・`#8fc1d4` 空・`#d4b483` 砂 です。

- 同じ人・対象の丸・帯・札は、全画面で同じ色にします。
- 色だけにせず、名前を必ず添えます。
- 識別色を系列色や操作の状態に使いません。識別色の塗りに白い字を載せるときは、白い字が読めるよう薄めません。

## 5. 作るときの扱い

- 色はすべて CSS の `:root` の変数にまとめ、各画面は用途に合った変数を使います。画面のためだけに似た色を増やしたり、色を直接書いたりしません。
- 新しい意味の色が要るときは、この文書と変数を先に直します（デザインの基本ルールの変更なので、design スキルでオーナーに選んでもらいます）。
- 国旗や外のサービスのロゴなど、決まった色はそのまま使います。
- 色を変えたら、375・1024・1440px と文字を大きくしたときに、文字・操作・選んでいる状態が読めるかを確かめます。文字と地のコントラストは 4.5:1 以上にします。
