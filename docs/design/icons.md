# アイコン

[部品 3-2](components.md#3-文字の表示はアイコン中心にして場所を取らない)「アイコンは全画面で1つの意味に決める」の一覧です。同じ絵を別の意味に使いません。新しい意味が要るときは、ここに1行足してから使います。

## 1. 描き方と置き方

- **絵はどれも線のアイコン**です。24×24、線の太さ2、角は丸く、色は文字と同じ色。アイコンのセットは1つに決め（標準は [Lucide](https://lucide.dev/)）、共通部品のアイコンの部品1か所から使います。
- **絵文字（📝 ⏰ 👥 などの色つきの絵）は使いません**。画面ごとに見た目が変わり、「1つの絵に1つの意味」も守れないからです。見本（モック）を作るときも、ここの線のアイコンを使います。
- **置き方は2つ**です。
  - 名前の頭に付けるとき（設定の行・タイル・通知の行・パネルの見出し）：**薄い青緑の角丸の四角**（44×44、角の丸み12、地は `--accent-weak`、絵は `--accent`）に入れます。小さく並べるときは30×30。
  - 札・チップ・選ぶ四角の中：四角を付けずに**線だけ**（16〜24）を文字の前か上に置きます。
- **一覧にない意味は、絵を足さずに文字だけ**にします。どうしても絵が要るときは、先にこの一覧に1行足してから使います。
- 状態を表す記号（✕ 休み・なし、⚠ 注意、✓ 済み・選んでいる、‹ › 前後、▾ 開く、› パネルを開く、→ 別の画面へ、＋ 追加、🔒 変えられない、ⓘ 説明）は文字の記号として使ってよいです。
- 外のサービスのロゴは、そのサービスの決まりどおりの画像で、四角を付けずに使います。

経緯：2026-11-06（[経緯](history.md#部品-3-アイコン)）。

| カレンダー・日付 | `calendar` |
| 時刻 | `clock` |
| 金額 | `wallet` |
| 写真を撮る・選ぶ | `camera` |
| 書き出し（CSV など） | `download` |
| 使い方 | `circle-help` |

| 削除 | `trash-2` |
