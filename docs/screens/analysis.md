# 分析画面

1本の配信のコメント数と、チャットを見る画面です。オーナーが選んだ形（案 A、2026-11-12、#2）。

## 使う人と最初の画面

| 使う人 | どこで | 何をしに開くか | 375px でスクロールせずに見えるもの |
| --- | --- | --- | --- |
| 配信のアーカイブを見返す人（PC が中心、ときどきスマホ） | PC・スマホ | コメントが盛り上がった時刻を見つけ、そこから動画を再生する。チャットを読んで確かめる | ヘッダー、配信のタイトルと「配信元・長さ・コメント数」、動画の枠、コメント数のグラフの上の部分 |

## 配置（案 A）

- 配色は [配色](../design/colors.md) の標準。グラフの棒は `--chart-1`、ピーク（いちばん多い所）だけ `--accent`。
- 1つの画面で、動画・グラフ・チャット一覧を行き来できる（画面を移らない）。
- **PC（1440px）**：上に URL 入力欄（別の配信を分析し直せる）。その下を2列に分ける。
  - 左（広い列）：配信のタイトル、配信元・長さ・コメント数、動画、コメント数のグラフ（上からこの順）。
  - 右（細い列）：チャット一覧。上に「キーワード・ユーザー名」の絞り込み欄。1行は「時刻（`--accent-dark`・太字）・名前（補足の色）・コメント」。
- **スマホ（375px）**：1列に縦に積む。上から タイトルと情報、動画、グラフ、チャット一覧（絞り込み欄つき）。URL 入力欄は出さず、トップへ戻る入口をヘッダーに置く。
- グラフの棒（または時刻）を押すと、動画がその時刻から再生される。動画が見えていないスマホでは、押したあと動画の枠までスクロールして再生する。
- チャット一覧の時刻を押しても、動画がその時刻から再生される。
- グラフ・動画・チャット一覧は、すべて白い面に細い枠、角丸 `--radius`。

## 状態

| 状態 | 見え方 |
| --- | --- |
| 読み込み中 | 動画・グラフ・チャット一覧の枠を、薄い面（`--surface-2`）の仮の形で出す。枠の位置は変えない |
| 空（コメントが0件） | グラフの枠に「コメントがありません」と補足の文字。チャット一覧は空の表示。動画は再生できる |
| エラー | 右上のお知らせ。画面の枠は残し、グラフ・チャット一覧の中に再読み込みの操作を置く |
| コメントが多い | グラフは棒を細かい時間の単位にまとめる（長い配信でも棒が潰れない）。チャット一覧はその枠の中だけを縦にスクロールし、画面全体の高さは変えない。PC は一覧の枠を画面の高さに収める |
