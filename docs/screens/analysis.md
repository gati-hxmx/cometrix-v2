# 分析画面

1本の配信のコメント数と、チャットを見る画面です。オーナーが選んだ形（案 A、2026-11-12、#2）。

## 使う人と最初の画面

| 使う人 | どこで | 何をしに開くか | 375px でスクロールせずに見えるもの |
| --- | --- | --- | --- |
| 配信のアーカイブを見返す人（PC が中心、ときどきスマホ） | PC・スマホ | コメントが盛り上がった時刻を見つけ、そこから動画を再生する。チャットを読んで確かめる | ヘッダー、配信のタイトルと「配信元・長さ・コメント数」、動画の枠、コメント数のグラフの上の部分 |

## 配置（案 A）

- 配色は [配色](../design/colors.md) の標準。グラフの棒は `--chart-1`、ピーク（いちばん多い所）だけ `--accent`。
- 1つの画面で、動画・グラフ・チャット一覧を行き来できる（画面を移らない）。
- **PC（1440px）**：上に URL 入力欄（別の配信を分析し直せる）。その下を2列に分ける。
  - 左（広い列）：配信のタイトル、配信元・長さ・コメント数、動画、コメント数のグラフ（上からこの順）。
  - 右（細い列）：チャット一覧。上に「キーワード・ユーザー名」の絞り込み欄。1行は「時刻（`--accent-dark`・太字）・名前（補足の色）・コメント」。
- **スマホ（375px）**：1列に縦に積む。上から タイトルと情報、動画、グラフ、チャット一覧（絞り込み欄つき）。URL 入力欄は出さず、トップへ戻る入口をヘッダーに置く。
- グラフの枠の見出しの右に「すべて｜笑い」の切り替え（#41）。「笑い」は「草」「w」「笑」などの笑いのコメントだけを数え、棒を `--chart-2` にする。見出しの下に「笑い N / 全 M 件」。
- グラフの下に「言葉・スタンプを重ねる」入力欄（#53、[仕様](../specs/53-keyword-lines.md)）。2つまで追加でき、言葉ごとに棒の上へ折れ線を重ねる（`--chart-2`・`--chart-3`、「笑い」の間は `--chart-3`・`--chart-4`）。線の縦軸は右側に別に取る。言葉は札で並べ、×で外す。
- グラフの棒（または時刻）を押すと、動画がその時刻から再生される。動画が見えていないスマホでは、押したあと動画の枠までスクロールして再生する。
- チャット一覧の時刻を押しても、動画がその時刻から再生される。
- 右の枠（スマホは下の枠）の上に「チャット｜メモ｜目次」のタブがある。選んでいる側は `--accent-weak` の地・`--accent-dark` の文字。チャット側は隠すだけで作り直さない（絞り込み・スクロールが残る）。
- 目次（#51）：今グラフに出している30秒ごとの数から、平均より多く3件以上の山を上位10件、数の多い順に並べる（120秒より近い山は1つにまとめる）。1行は「順位・時刻（`--accent-dark`・太字）・件数」、押すとその時刻から再生。今の再生位置に最も近い行は `--accent-weak` の地。詳しくは [仕様](../specs/51-toc.md)。
- メモ（#27）：複数行の欄、「今の再生位置を差し込む」ボタン（`[m:ss]`、1時間以上は `[h:mm:ss]` をカーソル位置に入れる）、欄の下のプレビュー。プレビューの時刻は `--accent-dark`・太字で、押すとその時刻から再生される。保存はブラウザ（localStorage、分析ごと、20,000 文字まで）。ログイン後のユーザーごと保存は #7 以降。
- 範囲（#58）：タブは「チャット｜メモ｜範囲」。始点・終点の入力欄（「ここから」「ここまで」で今の再生位置を入れる）、「グラフでなぞる」の切り替え（入れている間、グラフを左右になぞって範囲を選ぶ。範囲は `--accent-weak` で薄く示す）、［＋ 追加］。一覧は始点の早い順で、▶ の行を押すと始点から再生。名前・始点・終点を直せ、［削除］のあとは一覧の上に「削除しました［元に戻す］」。保存はブラウザ（localStorage、分析ごと、50 件まで）。仕様は [58](../specs/58-clips.md)。
- グラフ・動画・チャット一覧は、すべて白い面に細い枠、角丸 `--radius`。

## 状態

| 状態 | 見え方 |
| --- | --- |
| 読み込み中 | 動画・グラフ・チャット一覧の枠を、薄い面（`--surface-2`）の仮の形で出す。枠の位置は変えない |
| 取得中（#43） | タイトルの枠に進み具合のバー（地 `--surface-2`・塗り `--accent`、高さ 8px）と「42%（1:23:45 / 6:40:37 まで取得）」（`--accent-dark`・太字）。配信の長さが分からないときはバーを出さず「1:23:45 まで取得」だけ。取得後は「集計して保存しています」。順番待ちのあいだは「順番を待っています」 |
| 空（コメントが0件） | グラフの枠に「コメントがありません」と補足の文字。チャット一覧は空の表示。動画は再生できる |
| エラー | お知らせ（基本 8-1）。画面の枠は残し、グラフ・チャット一覧の中に再読み込みの操作を置く |
| コメントが多い | グラフは棒を細かい時間の単位にまとめる（長い配信でも棒が潰れない）。チャット一覧はその枠の中だけを縦にスクロールし、画面全体の高さは変えない。PC は一覧の枠を画面の高さに収める |

## もう一度分析する（#99）

完了した分析のタイトル欄の下、失敗した分析のお知らせの中に「もう一度分析する」ボタン（高さ 44px 以上）を置く。

- 押すと、その場で1回だけ聞く（部品 4-2。ブラウザの確認ダイアログは使わない）：「コメントと集計を消して、もう一度取得しますか？ メモは残ります。［戻る］［取り直す］」
- 「取り直す」で、コメント・集計を消して同じ ID のまま順番待ちに戻る。画面は読み込み中→取得中（#43）→新しい結果。メモ（localStorage）は分析の ID ごとなので残る
- 最後の更新から60秒は押せず、ボタンに「あと N 秒」を出す。取得中・順番待ちのときはボタン自体を出さない
- 失敗したとき（通信・待ち時間・取得中）はお知らせで伝える。失敗後に同じ動画の新しい分析が作られていたら、そちらの画面へ移る
