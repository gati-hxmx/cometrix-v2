# 共有ページ

分析の結果を、読むだけのページとして人に渡すための画面です（#68）。分析画面の左の列（動画・グラフ）と目次を、今ある部品のまま並べています。

## 使う人と最初の画面

| 使う人 | どこで | 何をしに開くか | 375px でスクロールせずに見えるもの |
| --- | --- | --- | --- |
| SNS や友だちからリンクを受け取った人（スマホが中心） | スマホ・PC | 配信のどこが盛り上がったかを見て、その場面を再生する | ヘッダー、配信のタイトルとコメント数、動画、「今の時刻のリンクをコピー」 |

## 配置

- URL は `/s/<鍵>`。鍵は分析ごとに1つで、分析の ID とは別にしている。共有ページとその絵・メタデータには、分析の ID・名前・本文・メモを入れない
- ただし動画の ID はページに出る（埋め込みに要る）。ログインがまだ無いので、同じ動画を分析しに行くと元の分析画面を開けてしまう。ログイン（D1）を入れるときに、分析画面を持ち主だけにする
- 上から順に、タイトルとコメント数の枠、動画、［今の時刻のリンクをコピー］、コメント数のグラフ、盛り上がった時刻（目次）。PC（900px 以上）では目次を右の列に置く
- グラフの棒と目次の行を押すと、山の 20 秒前から再生する（分析画面の初期値と同じ）
- `?t=90`・`?t=1m30s` を付けると、その時刻から再生する。［今の時刻のリンクをコピー］はこの形のリンクを作る
- 出さないもの：チャット（名前・本文）、よくコメントした人、メモ、範囲、絞り込み、⋮ メニュー
- 鍵が無い・共有をやめたリンクは 404 のページ
- 検索には出さない（`noindex`）。SNS に貼ったときの絵は出す

## 共有リンクを作る・やめる

- 分析画面の ⋮ メニューの［共有リンクをコピー］で作ってコピーする。2回目からは同じリンクをコピーする
- 共有しているときだけ［共有をやめる］が出る。やめるとリンクは開けなくなり、お知らせの［元に戻す］で同じリンクに戻る
- 鍵は分析ごとに一度だけ作り、やめても消さない（`shared_at` を空にするだけ）。鍵を外から受け取らないので、やめたリンクをほかの分析に付け替えることはできない
- 分析し直しのあいだ（終わるまで）と、分析し直しに失敗したあいだは、共有ページは 404

## SNS に貼ったときの絵

- 1200×630。配信のタイトル（38 字を超えると「…」で2行に収める）、コメント数のグラフ（96 本までにまとめ、いちばん高い棒を `--accent`）、コメント数、Cometrix の名前。色はライトの配色（`src/lib/app-colors.ts`）
- 日本語の字は、絵に書く字だけを Google Fonts（Noto Sans JP の太字）から取る。取れないときは字なしでグラフと Cometrix だけの絵にする。取った字はサーバーのメモリに 50 組まで覚える
- 無い・やめたリンクの絵は 404
- 絵の URL（`og:image`・`og:url`）は、環境変数 `APP_ORIGIN`（例 `https://cometrix.example`）があればそれ、無ければリクエストの Host と X-Forwarded-Proto から作る
