# #60 Twitch で作られたクリップの時刻をグラフに出す

## 目的

Twitch の VOD を見返す人が、視聴者がすでにクリップにした場面（＝見どころの目印）をグラフ上で見つけ、そこから再生したりクリップのページを開いたりできるようにする。競合（VODPeek）のクリップの時刻に相当する。見た目は [分析画面](../screens/analysis.md) の既存のグラフに印を足すだけで、新しい種類の画面ではない。

## 使う人と最初の画面

[分析画面](../screens/analysis.md) の表のとおり（変わらない）。印はグラフの中に置き、375px の最初の画面の見え方を変えない。

## 受け入れ条件

### 取得（ワーカー）
- Twitch の VOD の分析で、Helix API（`videos`・`clips`）から、その VOD で作られたクリップ（`video_id` が一致し、`vod_offset` がある）を取り、`jobs.result.clips`（`{ id, title, url, offsetSec, durationSec }` の配列）に保存する。DB のスキーマは変えない（`result` は jsonb）。
- `TWITCH_CLIENT_ID`・`TWITCH_CLIENT_SECRET` がないとき、`clips` は空にし、エラーにしない（分析は成功する）。
- クリップが0件のとき、`clips` は空。
- Helix の通信・解析が失敗したとき（HTTP エラー、壊れた JSON、タイムアウト）は `clips` を空にして分析は成功させる。Secret は外に出さない。
- ページ送り（`pagination.cursor`）は最大5ページ（最大500件）までで打ち切る。
- `vod_offset` が動画の長さの外（負、または最後のコメントの時刻を大きく超える）のものは含めない。同じ ID は1件にする。
- YouTube の分析では取得しない（`clips` は空）。
- 取得の解析は純粋な関数に分け、「クリップがない・鍵がない・壊れた応答」をテストする。

### API
- `GET /api/jobs/:id` の `result` に `clips` が含まれる。古い分析（`clips` がない）は空として扱う。

### 画面
- クリップが1件以上あるとき、グラフの上端に、クリップの時刻ごとの印（◆）を出す。印は `--chart-3` 塗り・`--warn` 縁のひし形で、ピーク棒（`--accent`）と区別できるよう、グラフの上の細い帯に置く。
- 印を押すと、その時刻（`offsetSec`）からプレイヤーが再生する。印の押せる範囲は 44px 以上。
- 選んだ印の近くに「クリップ：タイトル」と、新しいタブで開く「クリップのページ」リンク（`url`、`rel="noopener noreferrer"`）を出す。リンクの `url` は `https://clips.twitch.tv/` か `https://www.twitch.tv/` で始まるものだけを使い、それ以外は印を出さない。
- クリップがないとき・取得できなかったとき・鍵がないときは、印も説明も出さない（エラーのお知らせも出さない）。
- 拡大・移動したときは、表示範囲の外の印を出さない。
- 笑い表示でも印は同じ位置に出る。
- 375・1024・1440px で横スクロールが出ない。

## 範囲外

- 既存の分析の再取得（`clips` がない古い分析には出ない）。
- YouTube の「クリップ」・ハイライト。
- クリップの再生回数による重み付け、一覧表示。
- Helix の鍵がない環境でクリップを取るための非公式の手段（GraphQL）。

## 仮定

- クリップ取得は、タイトル取得と同じ Helix の Client ID／Secret を使う（Issue の「`.env` の Client ID / Secret」に合わせる）。新しい外部サービスではなく、既存の Helix の読み取りの追加なので `risk:low`。
- 保存先は既存の `jobs.result`（jsonb）にし、マイグレーションを避ける。必要になったら別 Issue で表を作る。
- Helix の `clips` は、`broadcaster_id` と期間（VOD の `created_at`〜`created_at + duration`）で絞って取り、`video_id` で VOD に合うものだけを使う。`video_id`・`vod_offset` が入っていないクリップ（VOD が消えた場合など）は出さない。
- 印は1本ずつ重ねて描く（近い印が重なるときは、押しやすさより位置の正確さを優先せず、重なった印は後ろの印を押せる）。まとめ表示は範囲外。
