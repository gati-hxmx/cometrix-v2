# #28 ダークモードと「見つかりません」の画面

## 目的

夜に使う人が目に優しい配色へ切り替えられ、選んだ方を次回も使えるようにする。存在しない URL を開いた人が、行き止まりにならずトップへ戻れるようにする。旧版（DarkModeToggle・NotFound）の移植。あわせて #35 の確認で見つかった「375px で横軸の時刻ラベルが詰まる」不具合を直す。

## 使う人と最初の画面

| だれが | どこで | 何をしに開くか | 375px でスクロールせず見えるもの |
| --- | --- | --- | --- |
| 配信アーカイブを見返す人 | スマホ・PC（トップ・分析画面） | 見た目を暗くする | ヘッダーの切り替えボタン（右端） |
| 古い・打ち間違いの URL を開いた人 | スマホ・PC | トップへ戻る | 見出し・説明・「トップへ戻る」ボタン |

## 受け入れ条件

### ダークモード
- ヘッダーの右端に切り替えボタンがある。押すと明るい↔暗いが切り替わる。ボタンは 44px 以上で、状態を文字（「ダーク」「ライト」）と記号で示し、`aria-pressed` を持つ。
- 初めて開くとき、保存した選択がなければ OS の設定（`prefers-color-scheme`）に従う。選んだ後は `localStorage` に保存し、開き直しても同じ。保存が使えない環境でも壊れず、その場の切り替えは効く。
- 画面が開く瞬間に正しい色で出る（明るい画面が一瞬光らない）。
- 色は `:root` の変数の値の差し替えだけで切り替え、`html[data-theme="dark"]` で上書きする。コンポーネントの色の直書きは変数に置き換える（例外は主な操作の白い字）。
- トップ・分析画面（グラフ・チャット一覧・メモ・再生バー・お知らせ・エラー・警告の面）すべてで、本文・補足の文字が地に対して WCAG AA（通常文字 4.5:1）以上。変数の組み合わせのコントラストを検査するテストを置く。
- グラフの系列色・選択・ホバー・再生位置の印も暗い地で見分けられる。

### 見つかりません
- 存在しない URL（例 `/xxx`）で HTTP 404 とともに「ページが見つかりません」の画面を出す。見出し・短い説明・「トップへ戻る」（`/` へのリンク、44px 以上）がある。ヘッダー（ロゴ・切り替え）も出る。
- 分析画面の存在しない ID は、今ある振る舞いのまま変えない。
- ダークでも読める。

### 横軸ラベル（#35 の指摘）
- 375px で、横軸の時刻ラベルが隣と接しない。狭い幅では目盛りの本数を減らす（幅から最大本数を決める。PC は今までどおり最大10本程度）。拡大・移動に追従する。本数と間隔を決める関数の単体テストを置く。

### 共通
- 375・1024・1440px で、明るい・暗いの両方を確かめる（横スクロールなし）。

## 範囲外

- 配色の細かい調整のやり直し（選ばれた案の範囲で差し替える）。
- サーバーへ設定を保存すること（ブラウザ内のみ）。

## 仮定

- 切り替えは「明るい／暗い」の2択。初回は OS の設定に従い、「自動」の第3の状態は作らない（旧版も2択）。
- 保存先は `localStorage` のキー `cometrix-theme`（`light`／`dark`）。個人情報ではないので高リスクに当たらない。
- 暗い配色の値はオーナーが design の見本から選ぶ。切り替えの仕組み・404・横軸は配色に依存しないので並行して進める。
- リスクは medium（自動マージ）。
