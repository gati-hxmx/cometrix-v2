# #41 笑いの盛り上がり（「草」「w」「笑」などのコメント数）

## 目的

アーカイブを見返す人が、コメントが多い場面とは別に「笑いが起きた場面」を見つけ、そこから再生できるようにする。[#29](https://github.com/gati-hxmx/cometrix-v2/issues/29) の候補1。競合（Highlight Analyzer）の笑い集計を参考にした。見た目は [分析画面](../screens/analysis.md)（案 A）と既存のルールの組み合わせで、新しい種類の画面ではない。

## 使う人と最初の画面

[分析画面](../screens/analysis.md) の表のとおり（変わらない）。切り替えはグラフの枠の見出しと同じ行に置き、375px の最初の画面の見え方（グラフの上の部分まで）を変えない。

## 受け入れ条件

### 笑いの判定
- 判定は `src/lib/laugh.ts` の1か所に書く。DB（Postgres の `~*`）と JS で同じ正規表現の文字列を使う。
- 笑いとみなすもの：「草」「笑」を含む／w・ｗ が2つ以上続く／英字・数字のあとでない w・ｗ 1つで終わる（「それなw」「w」）／英字にはさまれない lol・lmao・lmfao／haha…／😂・🤣・😆／YouTube の絵文字の名前（`:face-with-tears-of-joy:`・`:rolling_on_the_floor_laughing:`、区切りは `-` か `_`）。大文字小文字は区別しない。前後の空白（半角・全角スペース、タブ、改行）は除いて見る（JS と DB で同じ文字を除く）。
- 笑いとみなさないもの：wow・show・new・1w・lollipop・ha など。
- 1つのコメントに笑いの語が何回あっても1件と数える。
- 見本（`tests/fixtures/laugh-samples.ts`）で、JS と Postgres の判定が同じになることをテストする。

### API
- `GET /api/jobs/:id/buckets?laugh=1` は、笑いのコメントだけを30秒ごとに数える。区間の数は絞り込まない集計と同じ（0件の区間も含む）。動画開始前のコメントは除く。
- `q`・`xq`・`user`・`xuser` と同時に使える（両方に合うものだけ数える）。
- `laugh` は `0`・`1` だけ。それ以外の値は 400。
- DB の表・保存する集計は変えない（その場で数える）。

### 画面
- グラフの枠の見出しの右に、つながった札「すべて｜笑い」を置く（[基本 4](../design/layout.md#4-切り替えボタンの位置)）。初期は「すべて」。分析が完了しているときだけ出す。
- 選んでいる札は `--accent-weak` の地・`--accent-dark` の文字。札は押せる高さ 44px・幅 48px 以上。押した状態は `aria-pressed` で読み上げる。
- 「笑い」を選ぶと、笑いの数を読み込めた時点で見出しを「笑いの数（30秒ごと）」にし（読み込み中・失敗したときは「コメント数」のまま）、笑いのコメントの数で棒グラフを描き直す。棒は2番目の系列色 `--chart-2`、ピークは今までどおり `--accent`（[配色 3](../design/colors.md#3-グラフの系列色)）。
- 見出しの下に「笑い N / 全 M 件」を出す。絞り込み中は「絞り込み中：笑い N / 全 M 件」。
- 棒の説明・選んだ棒の表示は「0:12:30 から 笑い 3 件」。笑いが0件のときは「笑いのコメントがありません」。
- 拡大・選んだ棒は切り替えても保つ（グラフを作り直さない）。
- 読み込めなかったときは、お知らせ「笑いのグラフを読み込めませんでした。」（基本 8-1）。
- 375・1024・1440px で横スクロールが出ず、375px でも見出しと札が1行に入る。

## 範囲外

- 「すべて」と「笑い」を1つのグラフに重ねる表示。
- チャット一覧を笑いのコメントだけにする絞り込み。
- 判定の語をユーザーが変える設定。
- 時刻の目次・ライブ分析・ランキング（#29 の候補2〜4）。

## 仮定

- #29 の「コメント数とは別の線（またはスコア）」は、グラフを重ねずに切り替える形にした。既存の棒グラフと共通部品の組み合わせで作れ、375px でも棒が読めるため。
- 札は文字だけにした。基本 4 の「PC はアイコンを並べて選んでいるものだけ名前」は、「すべて」「笑い」に合う見分けやすいアイコンがなく、2文字・3文字で十分短いため。
- 「Shahaha」のように英字の中の haha も笑いに数える。
- 全角の「ＷＷＷ」の大文字小文字の無視は DB のロケールに依る（compose の標準と C.UTF-8 では一致。見本に入れてテストで気づけるようにした）。
- 「www.」のような URL も笑いに数えてしまうが、配信のチャットではまれなので許す。
- 笑いの集計は保存せず、その場で数える。ローカルで使う規模（1配信で数万件）では十分速いと見込む。遅ければ #3 の集計と同じく保存する形にする（DB の変更なので別 Issue）。
