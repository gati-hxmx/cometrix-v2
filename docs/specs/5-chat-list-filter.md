# #5 チャット一覧と、キーワード・ユーザー名での絞り込み

## 目的

配信のアーカイブを見返す人が、動画の再生位置に合わせて動くチャット一覧を読み、キーワードやユーザー名で絞り込んで、気になるコメントの時刻から再生できるようにする。見た目は [分析画面](../screens/analysis.md)（案 A）の右の列／スマホの最下段に従う。#4 の分析画面に足す。

## 使う人と最初の画面

[分析画面](../screens/analysis.md) の表のとおり。375px の最初の画面（ヘッダー・タイトル・動画・グラフの上）は変えない。チャット一覧はグラフの下にスクロールして見る。

## 受け入れ条件

### 一覧
- `done` の分析画面に、絞り込み欄つきのチャット一覧を出す。PC（1024px 以上）はグラフ列の右の細い列、スマホはグラフの下。
- 1行は「時刻（`h:mm:ss`・`--accent-dark`・太字）・名前（補足の色）・コメント」。
- 再生位置（プレイヤーの現在時刻）に近いコメントが出る。再生が進むと一覧は再生位置の付近へ追従する（約1秒ごとに現在時刻を読む）。現在位置に最も近い行は強調する。
- 一時停止・未再生のときも、現在位置（未再生は 0:00）付近を出す。
- 行の時刻を押すと、動画がその時刻から再生される（スマホは動画の枠までスクロール）。
- 一覧は枠の中だけを縦にスクロールし、画面全体の高さを変えない。PC は枠を画面の高さに収める。利用者が一覧を自分でスクロールしている間は追従で位置を奪わず、「再生位置に戻る」ボタンで追従を再開できる。
- 一度に取得して出すのは最大 200 件。
- コメント0件は「コメントがありません」、絞り込みで0件は「一致するコメントがありません」を出す。取得失敗は一覧の中に再読み込みの操作を置き、右上のお知らせでも知らせる。読み込み中は仮の形（`--surface-2`）。

### 絞り込み
- 欄は「キーワード」と「ユーザー名」の2つ。入力から 300ms 待って反映する。
- キーワードはコメント本文、ユーザー名は名前への部分一致。大文字小文字は区別しない。両方入力したときは両方を満たすもの（AND）。前後の空白は無視し、空欄は絞り込まない。各 100 文字まで。
- 絞り込み中、一覧は再生位置に最も近い「一致するコメント」から出る。
- 絞り込み中、グラフは一致したコメントの数で描き直される（同じ30秒区間・同じ棒の本数）。ピーク（`--accent`）も絞り込み後で決め直す。ツールチップは「一致 N 件」。グラフの上に「絞り込み中：一致 N / 全 M 件」を出す。
- 両方空に戻す、または「クリア」ボタンで、元のグラフ・一覧に戻る。
- 一致0件のとき、グラフに「一致するコメントがありません」を出す（動画は再生できる）。
- 絞り込みは URL に残さない。

### API（読み取り専用・DB スキーマ変更なし）
- `GET /api/jobs/:id/messages?q=&user=&aroundSec=&limit=`：コメントを `{ id, offsetMs, author, body }` の配列で、`offsetMs` 昇順で返す。`aroundSec` に最も近い `limit` 件（既定 100・最大 200）を選ぶ。`aroundSec` が無ければ先頭から。`limit`・`aroundSec`・`q`・`user` が不正（数でない・負・100文字超）なら 400、`done` 以外は 409、存在しない・形が違う ID は 404。
- `GET /api/jobs/:id/buckets` に `q`・`user` を足す。指定があるとき `chat_messages` から30秒区間ごとの一致数を数えて返す。応答の形 `[{ startSec, count }]` は変えない。「一致 N / 全 M」は、画面側が区間の合計（N）と `result.totalComments`（M）から計算する。`q`・`user` の不正は 400。
- `%`・`_`・`\` は文字として扱う（エスケープ）。SQL は必ずパラメータ化する。
- 判定・正規化・エスケープ・追従位置の選び方は `src/lib/chat-filter.ts` の純粋関数にしてテストする。

### アクセシビリティ
- 絞り込み欄にラベルを付ける。一覧は追従で自動に読み上げが続かないよう `aria-live` を付けない。一致件数だけ `aria-live="polite"`。行のボタンは 44px 以上押せる。

## 範囲外

- CommentStats、アイコン・スタンプ・スーパーチャットの再現。
- 正規表現などの高度な検索、ユーザー名の完全一致の切り替え。
- 絞り込みの URL 保存・共有。
- DB スキーマの変更・検索用インデックスの追加。
- ログイン・利用制限、Twitch。

## 仮定

1. 「グラフは絞り込んだコメントの数を表示」は Issue の仮定どおり。棒の本数・まとめ方は #4 のまま。
2. 一覧は全件を送らず、API が再生位置の近くの最大 200 件を返す。取得は現在位置が取得済み範囲の端に近づいたときと絞り込みが変わったときだけ（毎秒は取りに行かない）。
3. 絞り込みは DB 側で `lower()` の部分一致。保存済みコメントは変えないため、全角半角の差は吸収しない（許容）。
4. 絞り込み時のグラフは `chat_messages` を `floor(offset_ms/30000)*30` で集計する（#3 と同じ区間）。
5. 現在時刻は IFrame API の `getCurrentTime()` から読む。取れないときは 0:00 付近。
6. 新しい依存・外部サービスは入れない。リスクは `risk:medium`。
