# 58 切り抜きの範囲（始点・終点）

目的：配信を見返す人が、切り抜きたい場面を「始点〜終点」の組で残し、一覧から再生し直せるようにする。書き出しは B9、ログイン後の保存は D3。

## 受け入れ条件

- 分析画面の右の枠のタブが「チャット｜メモ｜範囲」になる。
- 作る（ボタン）：「ここから」で今の再生位置を始点に、「ここまで」で終点にする。両方そろって終点が始点より後のとき［追加］で範囲が一覧に入る。そうでなければ［追加］は押せず、終点が始点以前のときは「終点は始点より後にしてください」と出す。
- 作る（グラフ）：「グラフでなぞる」を入れている間、グラフの上を左右になぞった範囲が始点・終点の欄に入る（マウスも指も。向きは左右どちらでもよい）。なぞっている間は範囲を薄く出す。入れていないときのグラフの操作は今までどおり。
- 一覧：始点の早い順。1行は「名前（なければ「範囲 N」）・m:ss〜m:ss・長さ」。行の再生ボタンで始点から再生する。
- 名前：40 文字までの短い名前。行の欄で直せる。
- 直す：始点・終点は「m:ss」「h:mm:ss」で入力して直せ、「今の位置」ボタンでも入れられる。変えるたびには保存せず、入力が止まってから（欄を離れたときも）1回だけ保存する。不正な値・終点が始点以前の値は保存せず、行の中に理由を出す。
- 消す：［削除］で即座に消し、「削除しました［元に戻す］」を一覧の上に出す。［元に戻す］で戻る。次の削除をするか分析を離れると戻せなくなる。
- 保存：ブラウザの localStorage（分析ごと、キー `cometrix:clips:<jobId>`）。50 件まで。壊れた値は空として読む。保存できないときは「範囲をこのブラウザに保存できませんでした。」のお知らせ。
- 画面：375・1024・1440px で横にはみ出さず、ボタンは 44px 以上。

## 範囲外

- 書き出し（B9）、ログイン後の保存（D3）、範囲どうしの重なりの制限。

## 仮定

- 「元に戻す」付きのお知らせは今の Toast（失敗専用）を変えず、一覧の中の1行で出す（新しい見た目のルールを増やさない）。
- 「グラフでなぞる」は、既存のなぞり（拡大中の横移動・指での選択）と衝突するため、切り替えを入れている間だけ有効にする。
- 件数上限 50・名前 40 文字は localStorage の量を抑ける仮の値。
- 範囲の上限はグラフの終端（最後の区間の終わり）に丸める。
