# #56 スパム・コピペを除いて数える／正規表現で検索する

## 目的

荒らしやコピペの連投で、グラフに偽の山ができないようにする。あわせて、チャット一覧の絞り込みで正規表現も使えるようにする（競合：VOD Highlight Analyzer のスパム除外、Twitch VOD Chat Search の正規表現）。見た目は [分析画面](../screens/analysis.md) と既存の部品（札・チップ・入力欄）の組み合わせで、新しい種類の画面ではない。

## 使う人と最初の画面

[分析画面](../screens/analysis.md) の表のとおり（変わらない）。スパム除外の札はグラフの枠の見出しの行に置き、375px の最初の画面の見え方を変えない。正規表現の欄は #24 の絞り込み欄に足す。

## 受け入れ条件

### スパムの判定（`src/lib/spam.ts` の1か所）
- 「同じ人の連投」：同じ投稿者が、同じ文（前後の空白を除き小文字にしたもの）を、その人の直前の同じ文から 30 秒未満で投稿したら、2回目以降を数えない。最初の1件は数える。直前の同じ文が数えない側でも、連投が続く間は数えない（連鎖）。30 秒ちょうどは数える。
- 「長いコピペ」：前後の空白を除いた本文が 100 文字以上のコメントは数えない（99 文字は数える）。
- 動画開始前（時刻が負）のコメントは今までどおり数えない。
- 判定は JS の純粋関数（テスト用）と SQL（ウィンドウ関数 `lag`）の2か所に同じ規則で書き、見本で一致をテストする。

### API
- `GET /api/jobs/:id/buckets?spam=1` は、スパムを除いて30秒ごとに数える。区間の数は絞り込まない集計と同じ（0件の区間も含む）。
- `spam` は `0`・`1` だけ。未指定は `0`（従来どおり保存済みの集計を返す）。それ以外は 400。
- `q`・`xq`・`user`・`xuser`・`re`・`laugh` と同時に使える。スパムの判定は絞り込みの前の全コメントで行う（絞り込みで連投の「直前」が変わらない）。
- DB の表・保存する集計は変えない（その場で数える）。

### 正規表現の絞り込み
- 新しいクエリ `re=…`（繰り返し可、含める正規表現）と `xre=…`（除外する正規表現）。本文に対して大文字小文字を区別せず部分一致で当てる。`re` は複数あればどれか（OR）、`q`・`user` とは AND。`xre` に当たるコメントは、他に合っても残らない。`/messages`・`/buckets` の両方。
- 1つは 100 文字まで、1種類あたり 10 個まで（#24 と同じ）。
- 不正な正規表現（`(`・`[a-` など）は 400。画面では追加できず、欄の下に「正規表現として読めません」を出す。サーバーが落ちたり 500 にならない。
- 画面で追加するときは JS の `RegExp` で検査し、API 側は DB の検査エラーも 400 にする。両方で読める書き方だけを案内する（先読み・名前つきグループは使わない）。
- 1回の絞り込みは、重い正規表現でも止まらないよう DB 側で 5 秒を超えたら打ち切り 400（`bad_request`）にする。
- 絞り込み欄に「正規表現」の欄を足す：ラベル・文字入力・［追加］・追加したチップ（#24 の4欄と同じ作り）。「含める正規表現」「除外する正規表現」の2欄にする（除外は `--danger` 系の色と「除外」の文言）。
- 打たせない工夫として、よく使う形をチップ（押すと入力欄に入る）で出す：「数字だけ `^[0-9]+$`」「URL `https?://`」「1文字 `^.$`」「!コマンド `^!`」「同じ字の繰り返し `(.)\1{3,}`」。押しただけでは絞り込みに入らず、［追加］で反映する。

### 画面
- グラフの枠の見出しの右、「すべて｜笑い」の札の隣に、つながった札「スパム除外｜除外なし」を置く（基本 4）。初期は「スパム除外」。押せる高さ 44px 以上、`aria-pressed` で状態を読み上げる。分析が完了しているときだけ出す。
- オンのとき、グラフは `spam=1` の数で描く（絞り込み・笑いと同時に使える）。読み込み中は保存済みの全件のグラフを出し、読み込めたら置き換える。
- 数の表示：見出しの下に「スパム除外・数えた N / 全 M 件」を出す（絞り込み中は「絞り込み中：スパム除外・一致 N / 全 M 件」、笑いのときは「笑い」）。
- 読み込めなかったときは、お知らせ「グラフを読み込めませんでした。」（基本 8-1）。
- チャット一覧は、スパム除外の影響を受けない（全件を出す）。
- 375・1024・1440px で横スクロールが出ず、375px でも見出しと札・スイッチが折り返して収まる。

## 範囲外

- チャット一覧からスパムを隠す切り替え。
- 別々の人による同じ文の連投（コピペ荒らしの集団）の判定。
- 判定の閾値（30 秒・100 文字）をユーザーが変える設定。
- 正規表現のフラグ指定、URL への保存。

## 仮定

1. 「短時間」は 30 秒、「長いコピペ」は 100 文字とした（YouTube の上限 200 文字の半分。通常の長文感想は残す）。仮の値で、定数 1か所で変えられる。
2. 初期オンにするため、初期表示も保存済みの集計ではなくその場の集計になる。DB の変更（保存）は高リスクなので別 Issue にし、遅ければ後で検討する。
3. 正規表現は JS と Postgres（POSIX ARE）で細部が違う。共通で読めるものを案内し、DB が読めなければ 400 にする。`\d`・`\w` など両方で同じ意味の書き方は使える。
4. 笑い（#41）の判定は変えない。笑いとスパム除外は同時に使え、スパム除外が先に効く。
5. リスクは `risk:medium`（スキーマ変更・認証・課金なし、読み取りだけ）。
