# 57 スーパーチャット・ビッツをグラフに印で出す

## 目的
配信を見返す人が「投げ銭が集まった場面」を、グラフの印から探して飛べるようにする。

## 受け入れ条件
### 取得・保存（ワーカー）
- YouTube の live_chat で `liveChatPaidMessageRenderer` は種類 `paid`、`liveChatPaidStickerRenderer` は `sticker`、`liveChatMembershipItemRenderer` は `member` として保存する。通常コメントは種類なし（null）。
- スパチャ・ステッカーは金額の表示文字列（`purchaseAmountText.simpleText`、例 `¥500`）を保存する。メンバー加入・金額が読めないときは金額なし（null）で保存する（失敗にしない）。
- Twitch は、コメントのフラグメントにビッツ（cheermote）が含まれるとき種類 `bits`、金額は合計ビッツ数（例 `300 bits`）にする。含まれなければ通常コメント。
- 既存の分析（種類の列がない・null）は今までどおり表示でき、再取得は要らない。
- 取得のテスト：種類ごと（paid/sticker/member/bits/通常）と金額、金額欠けの境界を確かめる。

### API
- `GET /api/jobs/:id/messages` の各行に `kind`・`amount` を含める。`donations=1` で投げ銭（kind が null でない）だけに絞れる。`donations` が `1` 以外の値なら 400。
- `GET /api/jobs/:id/donations` は投げ銭を時刻順で返す（時刻・名前・金額・種類・文）。上限 MAX_LIMIT 件。分析が done でなければ 409、不明な ID は 404。

### 画面（分析画面）
- グラフ上に投げ銭の小さな印を出す。同じ30秒の区間に複数あるときは1つにまとめ、件数を出す。
- 印を押す／ホバー・フォーカスで「名前・金額・文」を見られる。押すと、その時刻へ飛ぶ（再生位置の移動とチャット一覧の追従）。キーボードでも操作でき、印にはテキストの名前（aria-label）が付く。
- チャット一覧で投げ銭の行は種類のバッジと金額で区別でき、「投げ銭だけ」の切り替えで絞れる。
- 印の色は配色の CSS 変数から選ぶ。赤は使わない。ライト・ダーク両方で背景と区別できる。
- 投げ銭が0件の分析では印も切り替えも出さない（空の表示にしない）。
- 375・1024・1440px で、印が重なって押せない・横にはみ出すことがない。

## 画面ごとの使う人と最初の画面
| だれが | どこで | 何をしに開くか | 375px でスクロールせず見えるもの |
| --- | --- | --- | --- |
| 分析済みの配信を見返す人 | 分析画面（`docs/screens/analysis.md`） | 投げ銭が集まった場面を探す | 既存のグラフ。投げ銭があれば印がグラフ内に見える |

新しい画面や新しい見た目の方向性は作らない（既存のグラフ・バッジ・切り替え部品の組み合わせ）。

## 範囲外
- 金額の通貨換算・合計ランキング。
- Twitch のサブ・ギフトサブ（コメントのデータに含まれないため）。YouTube のギフトメンバーシップも対象外。
- 取得済みの既存分析の再取得・自動の埋め戻し。

## 仮定
- **DB に列を足す**（`chat_messages.kind`・`amount`、ともに null 可）。マイグレーションなので **risk:high**。マージは人が承認する（#57 に反映済み）。
- Twitch のビッツは GraphQL のフラグメントに cheermote が含まれる場合だけ拾う。実際の応答の形は実機でしか確かめられないため、形が違えば通常コメントのままになる（壊れない）。未確認は PR に書く。
- 金額は表示用の文字列のまま保存し、計算には使わない。
- 印は30秒区間ごとにまとめる（既存のグラフの区間と合わせるため）。
