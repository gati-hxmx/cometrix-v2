# 指摘対応（address）

## 手順

1. 指摘を1件ずつ読み、対応する／しないを決める。
2. 対応するものは直してコミットし、`scripts/check` を通す。
3. 対応しないものは、理由をその指摘への返信に書く（誤り、範囲外、別 Issue にしたなど）。
4. すべての指摘に返信してから push し、再レビューを依頼する。
5. 往復の回数を数える。これが2往復目の対応で、相手の必須の指摘に同意できないときは、両者の主張と推奨案を PR にまとめて escalate する。

## 次に呼ぶスキル

- review（再レビュー）
- 2往復しても決着しない → escalate
