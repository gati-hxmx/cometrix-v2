# 人への相談（escalate）

人が入るのは [リスク基準](../../../docs/risk-policy.md) の「人が入る条件」に当てはまるときだけです。人は忙しいので、読んですぐ決められる形にします。

## 手順

1. 該当する PR か Issue に、次の形でコメントする。
   - **決めてほしいこと**（1文。はい／いいえ、または選択肢）
   - **推奨案**とその理由
   - 選択肢ごとの影響
   - 判断に必要な情報（差分の要点、両 AI の主張、試したこと、ログの要約）
2. `needs-human` ラベルを付ける。
3. `scripts/notify` で通知する。本文は「決めてほしいこと」と推奨案とリンクだけにする。
4. 待っている間、その Issue の作業は止める。ほかの Issue は進めてよい。
5. 人の返事が来たら（PR の承認、コメント）、`needs-human` を外し、元のスキルに戻る。

## 次に呼ぶスキル

- 人の判断のあと、元のスキル（merge-gate・spec・implement など）
