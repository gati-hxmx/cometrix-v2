# 動作確認（verify）

テストが通ったことと、実際に動くことは別です。実物で受け入れ条件を確かめます。

## 手順

1. 受け入れ条件を一覧にする。
2. アプリを起動する（ローカル、または PR のプレビュー環境）。本番のデータには触らない。
3. 条件ごとに実際に操作して確かめる。画面の変更は、[基本 10 の確認のしかた](../../../docs/design/layout.md#10-確認のしかた) をすべて確かめる（375・1024・1440px のスクリーンショット、最初の画面、言語、文字の大きさ、指だけの操作、空データ・長い文字列・エラーの状態）。
4. 可能なら、確かめた操作を E2E テスト（Playwright など）として残す。
5. 結果を表にする：条件・確かめた方法・結果（OK／NG／未確認と理由）。画面はスクリーンショットを付ける。
6. NG があれば implement に戻る。

ブラウザが使えない環境では、テストとコードの確認までを行い、「画面は未確認」と明記する。

## 次に呼ぶスキル

- すべて OK → ship
- NG あり → implement
