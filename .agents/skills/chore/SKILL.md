# 小さな定型作業（chore）

主に Codex が担当します。作ったものは Claude Code がレビューします。

## 対象

- 依存のパッチ／マイナー更新（メジャー更新は高リスクなので対象外）
- 文言・誤字・色・余白など1か所で済む修正
- テストの追加、原因がわかっている小さな不具合の修正
- 決まった手順の繰り返し（翻訳ファイルの更新など）

## 手順

1. `codex/<Issue番号>-<短い名前>` ブランチを作る。
2. 変更し、`scripts/check` を通す。
3. 変更が対象の範囲を超えそうなら止めて、Issue に「chore の範囲外」と書いて triage に戻す。
